# R7.5 preregistration — C1-SR spatial source reuse

Status: AUTHORIZED FOR ONE EXPERIMENT; no implementation or result exists yet.

Authorization follows final R7 hostile review `R7-F004-REPAIRED-5-COMPACT-HOSTILE-20260811` and the human’s conditional R7.5 approval. This is the same MobileNetV2/NV12 workload, not a model or workload pivot. R7 remains formally unaccepted.

## Hypothesis

Accepted C1 maps each output channel independently and repeats the same 3×3 Y/UV source taps across the 48 output channels. A spatial-major 4×4 tile can load each tile’s source patch once into threadgroup memory and reuse it across channels, reducing source reads without changing the pretrained operator.

## Fixed candidate

- Name: `C1-SR`; experimental C1 execution path, not C4 and not R6.5 revival.
- Input: accepted 224×224 video-range NV12, `r8Uint` Y and `rg8Uint` UV.
- Geometry: accepted exact source mapping, nearest-sited UV `(x/2,y/2)`, SAME bottom/right behavior.
- Operator: unchanged transformed pretrained 3×3 stem, source weights/offsets/bias, tap order, Float32 accumulation, post-accumulation ReLU6.
- Schedule: fixed 4×4 output tiles, 28×28 threadgroups, 128 threads; one threadgroup barrier after guarded 9×9 Y/5×5 UV loading; no tile/parameter sweep.
- Output/bridge: persistent Float32 CHW `[48,112,112]`, same `BufferBackedMultiArray` tail, one command buffer/encoder, unchanged `.all` policy.
- No model, precision, tail, threshold, or framework change.

## Comparison and protocol

One three-way comparison: fresh strongest B2, accepted C1, and C1-SR. Use the fixed 64-input output-blind corpus, Release configuration, explicit `.all`, same bridge/tail, same timing boundary, same environment metadata, and preserved raw records.

- Five separate benchmark processes.
- Each process: 20 warmup triples and exactly 240 measured triples.
- Six path permutations (`B2/C1/C1-SR`) cycled exactly 40 times per batch.
- Every path appears 80 times in each ordinal position per batch.
- Record batch identity, source sample, permutation, path, raw timing, order/position, AC power, Low Power Mode, and thermal state.
- Recompute all marginal and paired statistics from raw records using deterministic bootstrap metadata.

## Gates and budget

Correctness precedes timing: activation maximum absolute error `≤1e-5`; task top-1 agreement `≥0.995`; retain and report full top-1/top-5/probability comparisons; C1-SR must retain zero full RGB bytes and zero PlaneFuse element-by-element CPU activation-copy bytes.

C1-SR is useful only if it lowers end-to-end p50 versus fresh C1 by at least 5% with a positive paired 95% CI. T1 remains unchanged: a competition target requires at least 10% lower end-to-end p50 than fresh B2 with a positive paired CI. Beating rejected R6.5 is irrelevant.

Budget: one primary implementation, at most one evidence-driven corrective implementation, one quick Release benchmark, and confirmation only if materially promising. No sweeps, random tuning, polyphase retuning, Float16, Metal 4, MobileCLIP, beta installation, or new workload.

If C1-SR fails correctness, fails the C1 retention gate, or does not produce a meaningful application-level improvement, record the negative result, close all performance research permanently, retain C1, and proceed to R8/R9 productization with the strongest honest result.
